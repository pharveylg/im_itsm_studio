# Slide 3: Project Overview

## Project Overview

**Goal**  
Standardize analysis output across all OAS methodologies using a consistent 4-AREA structure.

**Before**  
- Inconsistent formats  
- Hard to compare reports  
- AI output varied widely

**After**  
- Unified 4-AREA structure  
- Consistent verdict symbols  
- Clear governance in OAS-000

# Slide 4: New 4-AREA Structure

## New Structured Report Format

Every OAS analysis now follows this consistent structure:

| Area | Purpose |
|------|---------|
| **AREA 1** | Planning / Investigation Quality & Evidence Strength |
| **AREA 2** | Core Assessment (Root Cause, Implementation, Timeline, etc.) |
| **AREA 3** | Actions, Validation & Recoverability |
| **AREA 4** | Governance, Risk & Overall Verdict |

---

# Slide 5: OAS-000 Governance

## OAS-000 – Governance Standard (v1.2)

**Role:** Parent governance standard for the entire library.

**Key Addition in v1.2:**
- Added **§16.1 Structured Report Format**
- Made the 4-AREA structure **mandatory** for all analyses
- Defined the **Verdict Symbol Standard**

**Impact:** All other standards must now follow this format.

# Slide 6: OAS-201 Major Incident Communications

## OAS-201 – Major Incident Communications (v1.2)

**Focus:** Communication compliance and stakeholder management during Major Incidents.

**New 4-AREA Structure:**

| Area | Content |
|------|---------|
| **AREA 1** | Communication Frequency Compliance (gap analysis, SOP requirements) |
| **AREA 2** | Ownership Gaps & Automation Opportunities |
| **AREA 3** | Sufficiency Assessment (Preliminary, Updates, Closed notifications) |
| **AREA 4** | Communication Quality Review & Consistency Findings |

**Example Output:** Incident Compliance Report with timeline gaps, breach verdicts, and automation recommendations.

# Slide 10: Verdict Symbols

## Verdict Symbols (Standardized Across All Standards)

| Symbol | Meaning | When to Use |
|--------|---------|-------------|
| ✅ | **Strong / Supported / Compliant** | Evidence clearly meets requirements |
| 🔴 | **Weak / Not Supported / Breach** | Evidence fails to meet requirements |
| ⚠️ | **Partial / Unknown / Risk** | Evidence is incomplete or indicates risk |
| **Adequate** | Meets minimum requirements | Acceptable but not exemplary |
